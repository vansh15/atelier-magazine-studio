    Reference

    Shortcuts & canvas gestures

    How to edit, remove and restore on the page — plus every keyboard shortcut.

    Editing the page

    Edit any headline, caption or story:Click the text
    Remove an element (restorable):Hover → × Remove, or Shift+Delete while editing
    Remove a selected photo frame, sticker or text box:Delete / Backspace
    Restore a removed element:Click ↺ Restore on the page, or Ctrl+Z
    Reposition a photo inside its frame:Drag the photo
    Move a sticker or text box:Drag its ✥ handle
    Add text anywhere:Double-click empty paper

    Canvas, Layering & Selection

    Undo / Redo History:Ctrl+Z / Ctrl+Y (Ctrl+Shift+Z)
    Duplicate Selected Text or Sticker:Ctrl+D / Cmd+D
    Send Layer to Back / Bring to Front:[ / ]
    Fine Nudge Selected Text/Sticker or Pan Slot:ArrowLeft / Right / Up / Down
    Coarse 5× Nudge / Pan Step:Shift + Arrow Keys
    Delete Selected Floating Layer:Delete / Backspace
    Toggle Editorial Layout Guides:G
    Deselect / Close Active Modal / Exit Reader:Escape
    Open Keyboard Shortcuts Cheat-Sheet:? (Shift + /)

    Spread & Reader Navigation

    Previous / Next Spread (when no layer selected):ArrowLeft / ArrowRight
    Jump to Front Cover Spread / Final Spread:Home / End
    Advance Spread in Reader Mode:Space
